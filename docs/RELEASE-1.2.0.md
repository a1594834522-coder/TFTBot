# TFTBot 1.2.0

产品方向改为玩家控制的“阵容助手”。取消自动锁定玩法和核心的逻辑；即使来牌、装备、海克斯一致，也只提供候选。选择主线后默认优先比较同玩法备选，玩家仍能浏览其它类型。

- 推荐、赌狗、84、95分类浏览；“设为主线”与“取消主线”明确由用户控制。
- 卡片展示核心/前排持牌、同行占主C副本、近人口过渡已持种数、海克斯机制关联。
- 追三目标只有玩家选择赌狗主线后产生；其它过渡牌不因自动信号而追三。
- 桌面显示主线双核实际出现过、支持数足够的九人口及以上变体，保留观测数和均名；不把它们宣称为本局升级收益。
- 浮窗保持原有简洁布局，手选主线与过渡仍通过同一条链路同步。

这些是数据参考。完整的变阵净成本、失败后的实际棋盘强度与上限操作评价仍需完善；没有自动游戏操作。详见 [主线阵容助手设计](COMPANION-EXPERIENCE.md)。
