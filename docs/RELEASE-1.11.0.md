# TFTBot 1.11.0

新增启动阶段的“这家店怎么留”：在阵容助手的当前补强页，比较主线、同类备选与同时兼留的当前核心购买组合，以及跳过这家店的后续结果。

- 花费、双核补齐、搜后单场模型参考和预计余金分列，不把金币与战力混成一个分数。
- 总预算包含当前买牌，可在表格旁调整；与原搜牌预算同步。
- 保留失败、未评分与未知对手质量；原棋盘可合法重放时提供保守下界，升星破坏原实体时不借用旧战力。
- 延续墨色界面与精简浮窗。玩家保留选择权，不自动买牌、高亮或更改主线。

这是固定购买规则下的条件比较，不是完整的自适应最优策略。较复杂的商店需要数秒；真实排位收益仍待验证。详见CURRENT-PURSUIT.md。

验证：646项测试、类型检查与桌面构建通过；十组计算子进程场景及最终EXE的隔离原生留牌、预算同步和装备承接联调通过。它们验证工程链路，不证明排位收益。
