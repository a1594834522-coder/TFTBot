# 围绕玩家主线的阵容助手

目标是让玩家把自己选择的阵容玩得更顺、更灵活。系统提供推荐和可比较的数据，玩家决定主线、过渡、变阵与追上限；不自动收窄为唯一答案，不自动操作游戏。

## 一局游戏里的五类支持

| 环节 | 玩家真正需要的帮助 | 数据与交互 |
| --- | --- | --- |
| 选好主线 | 这套属于一、二、三费赌狗，84还是95；核心、前排和可替代位置分别是谁 | 按真实核心、星级、搜牌与终局人口记录分类，保留用户选择 |
| 前期过渡 | 当前来的牌里谁能打工、谁值得留、装备暂时给谁 | 真实前期棋盘关联、持有与缺失、出装兼容；允许与终局零重合，过渡由用户选择 |
| 启动搜牌 | 目前缺首张、关键二星还是双核二星；现有预算大致能到哪 | 等级、现有金币、购买费、同行占牌、有限牌池补齐概率，信息不完整时明确未知 |
| 临场变阵 | 主线抽不齐时有哪些同装备或相近玩法的替代方向 | 默认展示同玩法核心备选，也允许跨类型查看；比较装备、持牌、竞争和补齐难度，不替用户切换 |
| 成型后补强 | 补功能位、换核心、追星或采用更高人口变体，各自需要什么 | 展示真实高人口棋盘、已有英雄及原始统计；逐步增加实际替换成本和对同一候选对手的战力比较 |

## 已落实的交互

- 页面名为“阵容助手”，支持推荐、赌狗、84、95浏览。自动信号只影响推荐顺序，不能设置主线。
- 只有点击“设为主线”才改变当前参考与浮窗高亮；新装备、海克斯或来牌不会自动替换用户主线。可以随时取消或切换。
- 主线候选卡展示主C/前排持牌、同行占主C副本数、过渡已持英雄种数、海克斯机制关联。机制关联不是因果胜率提升。
- 未选择赌狗主线，不因自然来牌或海克斯自动开始追三留牌；普通过渡以两星参考为上限。
- 采用数据中确实保留同一双核、九人口及以上、支持数足够的棋盘作为后期变体。不会把互不相关英雄拼成上限图，也不保证高人口样本均名能复现。
- 复杂比较在桌面；浮窗保留主线/所选过渡头像、剩余牌数、悬停刷新费和战斗参考。
- 1.3.0：已选主线的过渡也能在桌面查看并选择。候选来自该家族完整的前期关联，按当前人口、已持种数与升级基础比较；不以终局重合度筛掉零重合过渡。选定方案跨人口与持牌变化保留，桌面和浮窗双向同步。
- 八人口后过渡面板默认收起，玩家手动展开后保持展开；选用主线不自动勾选过渡。未知持牌显示待同步，不伪装成零张。
- 候选卡可展开“承接与缺口”：把当前场上沿用、已持待上和缺失首张分开，显示实际参考棋盘人口、双核星级副本缺口，以及已穿装备、闲置物品和未来装备承接。仅列标准买价，不混入刷新费、卖牌回收或升级费，不生成拆掉过渡棋盘的指令。
- 1.4.0：“当前换牌”比较购买/自然合成后最多两张牌联动替换的棋盘，显示实际上下场、升级与装备；手选主线在启动/后期另有双核接入或保留方案。每个方案都用相同对手分布与同一真实棋盘基线比较，允许主线方案暂时更弱并如实显示。
- 1.5.0：实时战斗保留拉克丝形态，牌库仍按同一英雄计数；非商店单位按原始模型契约处理，来源确认的假人保持在候选棋盘上。伙伴召唤物只在来源实体与装备保持时参与换牌比较，当前没有猜测具体骑乘者。
- 1.6.0：商店补强相对最佳免费换牌棋盘计算购买的额外收益，保留不同成本的组合，整组手选高亮且不改变主线；实时局面变化后失效。当前商店已有目标显示无需刷新，不与未来下一张费用混淆。
- 1.7.0：启动搜牌增加包含未齐分支的预算落点，对主线与兼留备选分别计算当前装备/对手条件下的模型参考、变弱风险和未齐条件平均；未知或未评估分支保留上下界。当前仍非完整自适应搜牌策略，部署范围与装备承接边界见SEARCH-LANDINGS.md。

## 主线是可达路径，不是一张固定八人名单

玩家选择的是阵容家族。系统应持续回答“用眼下资源怎样把这套玩好”，并允许玩家查看同家族分支和相近装备的外部备选。不能用终局重合度衡量前期过渡，也不能仅因来了一张四费就替换已经两星、带装的打工核心。

| 阶段 | 应比较的目标 | 必须保留的信息 |
| --- | --- | --- |
| 过渡 | 眼下可组成的棋盘、下阶段可达棋盘、装备打工与承接 | 实际星级与上场能力；终局零重合的强过渡正常参与；备战席所有权不等于场上战力 |
| 启动 | 主线首核、关键二星、双核二星，以及能共留的替代核心 | 已见商店、现有预算、同行占牌、买牌费用；抽不齐后的可保留棋盘，不能只看最终成功概率 |
| 成型 | 已完成关键核心后，功能位和羁绊的具体替换 | 在相同对手分布下比较当前与替换后棋盘；缺核心二星不等于一定弱，八个名字齐也不等于稳定 |
| 上限 | 主线追星、高人口变体、五费承接和针对性功能位 | 装备去向、移除单位的功能损失、真实人口与可达成本；九人口样本均名不能当本局升九收益 |

三类玩法共用数据层，采用不同目标：赌狗区分一至三费核心追三与追成后的补强；84重视启动失败仍能打的混合棋盘和双核承接；95重视在获取高费核心前保留强过渡，再比较逐步替换。95不是凑齐五费名单，84也不是4-2一次换完全部目标单位。

最终比较应保留战力、装备承接、可达代价和后续分支几个独立维度，展示少量各有优势的方案。历史聚合用于产生真实候选与装备关联，牌池模型衡量可达性，战斗模型比较具体合法棋盘。未建立因果校准前，不把这些量任意加权成一个“上分分数”。主线与过渡变更始终由玩家确认；日常来牌只刷新事实，不反复弹出改阵提示。

## 体验验收：从开局选择一套阵容开始

以下是产品与算法的验收目标，不表示当前已经完整实现。玩家选定的是一个阵容家族及偏好，日常来牌不能替玩家改变主线。重点从“这套阵容名单里有什么”推进到“眼下怎样把这套玩好”。

### 主线内的阶段与分支

每套主线需要可追溯的玩法依据：主要投入的核心及目标星级、常见启动人口、实际前期关联、装备承接者、成型变体。赌狗继续区分一、二、三费核心；84允许启动后的混合棋盘；95保留进入高费核心前的打工阶段。若同一家族确实存在两种玩法，应作为可选分支展示，不能只看终局平均费用或固定回合强行归类。

阶段不能仅由回合决定：同在4-2，可能仍在过渡、已抽到首核、关键二星已成或主线核心尚未到手。每次建议应对应实际状态，并允许玩家选择继续主线、兼留备选或查看上限。

### 留牌不是终局名单的并集

在当前棋盘、备战席、商店、装备实体、海克斯、预算和可用牌池的同一快照下，比较购买一张牌与不购买后的合法后续方案。至少分开衡量：当前可上场的改善、装备承接、主线里程碑的推进、失败后可保留的分支，以及占用的购买金币。不能把同一件装备同时分给多个输出位，不能把备战席已有牌当成场上战力。

牌的用途可以是即时升级、临时打工、未来接装、路线共用或主线核心。零终局重合的过渡正常参与；主线里的挂件也不必开局全留。多个方向共同出现的英雄，只有确实保留了可达路径才算增加选择价值，不能用出现次数代替实际价值。

历史聚合提供候选和关联证据；牌池与购买模型计算获取代价；单场战斗模型比较具体棋盘。三类量保留各自含义，未经校准不能合成一个声称代表上分概率的总分。前期强棋盘与某个终局共同出现，也不足以证明该过渡对这套终局有因果优势。

### 搜牌与变阵需要比较失败后的落点

4-2/4-3启动的目标不止是双核二星。需要在同一预算下保留首核、关键二星、混合棋盘与完整成型等落点，并比较没抽齐时的真实可用阵容。备选核心是否值得留，要结合当前星级、可承接装备、同时保留的成本与可替代位置。不得把尚未实现的完整路径搜索展示成最优搜牌策略。

变阵默认先比较同主线功能位替换与装备兼容分支，再提供跨家族备选。提示展示具体新增与移除、装备去向、实际可计算成本，以及同一对手分布下的模型变化；不因备选终局历史均名更好就要求玩家转阵。主线仍有可行落点时，玩家可以继续原计划。

### 上限是净改善，而不是更多高费牌

成型后比较追关键星级、补控制或减抗、替换弱功能位、高人口扩展及高费承接。必须考虑拆掉原单位造成的羁绊、前排和装备承接损失。当前与替换后使用相同对手集合及权重；真实下一对手候选未验证时只能标为全场参考。没有站位输入的模型结果不能表示站位优化收益。

### 界面与具体反例验收

浮窗只保留所选主线/过渡英雄及剩余张数、商店留牌高亮和简短战斗参考。路线原因、成本、装备去向和其他方案留在桌面，展开查看；没有明显新信息时保持顺序稳定。当前商店已出现的牌应显示可直接购买，不再展示需要重新刷到的费用。

上线前应逐项通过可复现的反例：

- 前期强过渡与终局零重合时仍能推荐，并解释实际装备承接。
- 两星带装打工核心与一星终局核心同时存在时，不仅因名字匹配就建议替换。
- 主线连续未到核心、备选已到关键二星时，提供可继续作战的备选，保留玩家选择权。
- 同样主线与同样持牌，装备、海克斯或关键同行占牌改变后，建议体现具体变化。
- 追三已完成后转向补强；九人口替换破坏关键功能时，不因高费身份就标为提升。
- 实时字段缺失、过期或相互冲突时保留资料浏览，停止对应的不可靠精确计算。

工程回放通过仅证明输入处理和建议逻辑满足这些场景；真实排位收益仍需整局读数与后续实战验证。

## 尚待完善

当前已经能展示和计算参考，但还不能宣称找到了“最好的过渡”“最好的变阵”或“最高上限操作”。两牌联动比较已使用实际单场模型，参考追牌策略的失败落点也已接入；任意自适应失败路径、超过两牌的整体变阵、卖牌后的装备承接、更多装备位及多副本跨路线选择仍需完善。实际下一对手候选字段待游戏验证。模型没有站位输入；来源未确认的独立单位、骑乘者更换后的召唤物，以及假人历史属性尚未完整建模。

下一步应把当前两牌联动扩展到更完整的混合棋盘与装备承接，完善非商店单位联动和根据真实战力自适应取舍的搜牌策略。尚未计算完整路径的最优战力，也未验证排位收益。提示应对应明确的新信息，例如关键升级到手或追三空间不足；不持续发出要求玩家改变路线的指令。
