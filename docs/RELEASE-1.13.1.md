# 1.13.1 · 减少重复留牌计算

实时更新和目标切换时，留牌计算现在复用条件一致的牌池转移、冻结策略与对手加权棋盘数值。新商店仍重新核对买牌花费、合成、装备、形态和实际对手，不直接展示旧建议。

完全展开的策略可用于已经覆盖的后续金币/副本状态；触及额度的策略仅在起点与计算条件完全一致时原样复用。取消中的未完成策略不写入缓存，旧快照数字继续立即失效。主线、预算、目标和所有游戏操作仍由玩家决定，界面保持1.13.0的墨色布局。

一次真实本地MetaTFT模型的合成对照中，同一40金局面重复比较从约4.89秒降至1.14秒；支付刷新费后的38金新商店从4.15降至3.05秒，再刷新到36金新商店从3.55降至0.91秒。每次均保留24种买牌组合、48个商店情景和384落点评估，数值保持一致。首次计算约5.53秒，实际牌池/持牌变化可能需要重算，不能保证每次刷新都达到上述速度。详见[PURSUIT-REUSE.md](PURSUIT-REUSE.md)。

672项测试、类型检查和12个独立计算进程场景通过，包括独立物理副本枚举、缓存失效、受限表隔离、取消、实体装备与未知对手的重新验证。原生协议事件及最终便携包另验证目标来回切换、真实缓存命中与原结果一致。并发检查曾使关键二星场景超出15秒；隔离复核并优化重复达标条件后，最终同场景约9.62秒完成，未延长检查时限，仍需实局核对复杂冷启动延迟。

原生采集仍依赖本机`E:/amumu`。真实候选对手信号、连续整局稳定性和排位收益仍待验证；本次改善工程响应，不据此宣称决策已能稳定上分。
