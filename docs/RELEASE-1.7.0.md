# TFTBot 1.7.0

增加搜牌“预算落点”：比较主线优先与兼留备选，在没凑齐核心时还剩下什么战力。

- 从已见商店开始逐次扣除购买费和刷新费，计算包含成功及未齐分支的持牌分布；保留动态有限牌池，不预知未来商店。
- 新增副本与实际购买共用常规合成及装备规则，还原实际星级与原穿装备，不把未齐分支直接赋值为0。
- 桌面展示预算后模型参考、核心未齐概率、低于当前免费换牌基线的风险；展开查看没抽齐时的条件平均与一个可能棋盘。
- 4/5英雄格分情景切换。未展开、未评估、未知规则或缺失对手保留概率质量与上下界，不伪装成完整确定结果。
- 保留玩家主线选择，核心已齐后转去换牌与上限参考。计算在独立进程完成，实质局面变化取消旧结果。

入口为玩家已选主线的启动/后期、七人口以上，需可用的全场持牌与当前对战棋盘。部署仍限两牌联动，装备留在原实体上；不含卖牌接装、任意整体变阵、未来收入/人口或对手成长。这是可比较的参考策略，并非最优搜牌算法或已验证的排位收益。

613项测试、类型检查和构建通过；独立计算进程通过含新预算落点的7种场景，最终EXE通过普通、召唤物、购买组合和预算落点四种私有原生通道联调。布局检查与实际截图确认情景切换、展开细节、无横向溢出和主线保持。全部是合成协议输入，未运行真实游戏。
