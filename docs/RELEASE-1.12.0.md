# TFTBot 1.12.0

“这家店怎么留”新增可主动选择的“补齐优先”，默认仍为升星优先。

- 根据每家已揭示商店，比较购买子集、继续刷新和停止；保留买牌费用、共享池与失败分支。
- 同一表格中的补齐机会、搜后单场模型与余金来自同一目标策略。切换时隐藏旧目标数字，主线与实际游戏由玩家控制。
- 搜索达到额度后保留未知区间，只在能证明改进时改变基础动作；受限搜索不宣称全局最优。
- 原生桌面验证了目标切换、切回、预算同步和后续装备承接。

更容易补齐不代表更容易赢：固定20金合成样例里，补齐优先保留了更多预算，但当前单场模型参考下降。真实排位效果仍待验证。计算与证据详见ADAPTIVE-PURSUIT.md。

验证：659项测试、类型检查、桌面构建及十一组计算子进程检查通过。最终EXE完成原生目标切换、切回、预算同步与装备承接联调；一次切回约1.62秒。新增步骤使用独立的测试总时限，生产运行不受该测试时限影响。
