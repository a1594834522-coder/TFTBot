# TFTBot 1.10.1

桌面界面采用受 Anthropic 启发的克制风格：墨色与暖灰作为底色，米白文字，少量陶土色标记当前位置和主动选择。

- 统一桌面导航、阵容、决策模块、海克斯评级、对局面板与设置的色彩层级，窗口标题栏同步。
- 标题使用衬线字体，数据和操作使用系统无衬线字体；提高辅助文字与关键数字的可读性。
- 降低背景插画存在感，减少装饰性描边；阵容长名称可换行，并可悬停查看。
- 阵容助手图标改为功能性面板图形，保留清晰的选中标记与键盘焦点。
- 局内浮窗保持紧凑布局。此版本不改变计算、数据来源或主线选择逻辑。

验证：类型检查与桌面构建、设计预览交互检查（含 1080×720 最小窗口）、最终桌面包启动检查。
