# TFTBot 1.4.0

阵容助手的“当前换牌”开始支持两张牌联动：购买与自然合成后，比较最多换下两个场上实体的合法棋盘。保留当前不动的棋盘作对照，仍不自动操作游戏。

- 手选主线进入启动或后期阶段后，另列主线双核接入/保留的参考；眼下较弱的主线方案也会如实显示负向模型变化，不替换当前战力方案。相同棋盘不重复展示。
- “换牌明细”展示换上、换下、自然合成升级和最终上场装备。原持装备随实体保留，合成按实际账本转移；不会把打工牌装备凭空分给新核心。
- 本方场上实体、星级与装备必须和战斗基线一致。备战席装备未知或模型未覆盖的候选单独排除，仍可比较其余有效棋盘。
- 对照方案使用相同对手分布。缺失对手的概率质量保持未知，不重新归一化成完整胜率。
- 候选生成与模型批次之间允许取消，过时局面不会继续发布新数字。桌面版本号改为从构建版本读取。

边界：这是当前商店和持牌下的有限换牌搜索，尚未计算完整启动路径或最终名次最优策略。MetaTFT 此模型不含站位输入；本轮不模拟拆卸、卖掉打工牌后的装备承接。含非商店战斗单位时，其随换牌变化的规则尚待接入，当前会明确停比较，避免把它们从候选棋盘中静默删掉。

验证包括独立组合枚举、双牌协同、主线保留、装备实体与自然合成、不同对手权重、未知对手质量、未知装备和取消旧局面。真实模型的八人口合成审计可运行 `node scripts/audit-startup-deployment.mjs`；此样例不是实战回放或排位收益校准。

566个测试、类型检查和桌面构建通过。正式打包EXE通过采集、换牌明细、主线/过渡双向同步、胜率、仙灵和浮窗联调；独立计算进程通过模型故障隔离、无对手下个人参考，以及4-2手选主线双核场景。八人口样例比较11种合法购买组合、757个不同棋盘，本机本次约0.42秒；这不是所有局面的延迟保证。
