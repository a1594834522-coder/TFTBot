# TFTBot 1.1.1

新增候选对手字段的被动采集探针：记录玩家名单未知字段、新事件及回合变化，保留尚未通过解析的原始证据，并提供离线字段审计脚本。

工作区 `启动TFTBot.cmd` 自动开启本地监控。所有日志均在 `dist/`，不会随源码推送。此版本仍未确认头像候选角标对应的原生字段，继续使用全场等权胜率，不根据猜测排除对手。

增加字段变化、重复帧、限流、未知事件和日志写入回归测试；540个测试、类型检查与桌面构建通过。

数据重建脚本改用 `METATFT_REFERENCE_DIR`，去除开发者机器上的个人目录依赖；正常构建继续直接使用仓库数据快照。

原生采集仍依赖本机 `E:/amumu` 组件。真实候选语义需要下次实局对照，今天没有游戏画面，不宣称已打通候选对手读取。
