# TFTBot 1.9.0

桌面界面重新组织为侧边导航和三个战术工作区，减少长页面中重复的信息。视觉采用墨色、暖灰和米白，撤去大面积紫色、渐变与装饰性标签。

- 采用墨色与暖灰底色、米白文字、少量陶土色强调、线性图标和轻边框；主窗口使用集成式 Windows 标题栏，保留原生最小化、最大化和关闭操作。
- 阵容浏览保留中文名称、评级、头像、聚合样本及站位，明确当前主线，缩小资料筛选栏。
- 阵容助手分为“阵容与过渡”“当前补强”“搜牌与上限”。切换时保留主线、过渡与明细状态；三个工作区可用方向键、Home、End操作。
- 当前等级和金币单独呈现；装备承接以头像路径与模型变化为主，容量条件始终可见，长篇数据依据按需展开。
- 移除英雄资料独立页面及头像双击跳转，英雄头像保留阵容筛选用途；海克斯和设置页统一样式，设置开关补齐无障碍名称。
- 包含1.8.0的装备承接实现；不增加局内浮窗内容，不自动改变玩家主线。

验证：623项测试、类型检查和桌面构建通过。隐藏Electron页面核对1080/1280/1440宽度、60套MetaTFT阵容的筛选与手选、预算交互、键盘焦点、过渡双向同步和刷新保持；打包EXE核对五组隔离原生协议场景。界面示例使用合成对局，不作为真实识别或排位收益证明。

仅最新S18。部分图片依赖远程资源；实时采集仍需本机原版原生组件。算法数据条件和待实局校准范围见各模块文档。

本机已于2026-10-21更新至1.9.0，固定启动目录保留上一版备份；未自动启动采集或游戏浮窗。
