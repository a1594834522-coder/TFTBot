独立桌面版对局面板接收原版原生 GEP 的 tft_roster / players_info，按玩家身份合并，二星折算 3 张、三星 9 张、四星 27 张。统计存活玩家，淘汰后归池；缺失明细与明确空棋盘分开处理。停止、断开、采集异常、对局结束会清空实时状态。录像不被没有新记牌数据的商店事件覆盖。

数据参数：data/current-shop-mechanics.json，来自用户提供的 MetaTFT S18 PBE 参考表，仅 S18。65 个普通商店英雄，按共享牌池合并拉克丝等不同形态。正式服数值尚待核对，界面明确标注来源。当前等级优先使用实测 tft_xp.xp_level，保留手动模拟。全场明细缺失、含部分覆盖、过期或含未匹配单位时不输出金币数值。对手棋盘来源为 tft_opp + tft_board_opponent，仅计已观察部分；全场记分板见 ORIGINAL-RECOGNITION.md。

## 刷牌模型

目标剩余 R 张，同费用剩余总数 N，该等级该费用概率 p。5 槽里该费用槽数 K 服从 Binomial(5,p)。同费用英雄无放回抽取，因此一次刷新未命中概率为：

sum(k=0..5) C(5,k) p^k (1-p)^(5-k) × product(i=0..k-1) (N-R-i)/(N-i)。

一次命中概率 h=1-未命中概率。平均刷新花费 2/h；达到 q 命中把握的刷新预算为 2×ceil(log(1-q)/log(1-h))，展示 50% 和 90%。当前商店已有目标则刷新预算 0；购买英雄费用另列。牌池耗尽或等级概率 0 返回不可达，不产生 Infinity。特殊的极小牌池不假设补位规则。

假定刷新 2 金、其他玩家状态和等级不变，未购买商店在刷新时归池。不计算其他玩家商店暂占、复制生成单位、免费刷新和特殊商店。预算是条件概率估算，不是保底。

## 2026-10-20 算法独立复核

复核样本冻结为此前实局输入：6级一费概率0.30、目标阿卡丽剩24张、同费牌池剩345张。复核范围是普通商店、每次付费刷新2金、5槽，等级和全场持牌不变，未购买的商店在下一次抽取前归池。此假设下，每次失败后重置到相同牌池，下一张命中等待时间服从几何分布；单刷命中率为h时平均额外刷新费为2/h。

独立校验测试：`tests/roll-odds.test.ts`。一组按五个槽位逐一枚举费用/目标/非目标分支，覆盖多种概率、牌池与剩余目标数；另一组使用有实体副本的牌堆随机抽取，抽同费牌后移出牌堆，每次失败刷新结束后恢复牌堆。没有用生产函数的命中率来伪造随机成功事件。

固定种子结果：

| 校验 | 结果 |
| --- | --- |
| 公式每次刷新至少一张的命中率 | 0.10024158813188694 |
| 500000个商店的模拟命中率 | 0.100828 |
| 公式平均刷新费 | 19.951798821948216金 |
| 200000条刷到下一张为止的模拟轨迹 | 19.95311金 |
| 50% / 90%命中预算 | 14金 / 44金 |

分位数额外检查：该预算的累计命中率达到目标，少刷一次仍达不到目标。20金是10次刷新，累计命中率约65.23%。不能把平均刷新费理解为保证出牌所需费用，也不能把多张追牌/升星的花费直接乘成固定值；本功能只估计下一张。

发现并修复一个数值边界：极小正概率时用1减接近1的未命中概率会丢失有效精度，误报0。现保留二项式与超几何模型，用log1p/expm1计算各分支命中概率再求和。这个问题不影响本次0.30、24/345的结果。

模型可通过数学和模拟验证，但真实输入还有范围限制：参数来自标明的S18 PBE快照；其他玩家商店暂占、特殊刷新费用或规则、免费自然刷新与动态买卖并未纳入。同一套公式模拟吻合不能证明这些游戏机制已经实测确认。客户端6级一费概率仍需对照游戏显示；相同牌池换用25%时，均值会相应增大。此次校验不重启正在采集的对局助手。
