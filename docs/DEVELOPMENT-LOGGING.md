# 开发记录版

双击根目录的`启动开发记录版.cmd`。启动器先构建源码，成功后关闭本项目旧实例，再启动开发记录版和只读采集；不替换固定的1.13.1便携程序。沿用单实例机制与现有配置，F8仍控制浮窗。

每次启动使用独立的`dist/live-monitor/dev-时间/`目录，当前入口信息保存在`dist/tonight-development.json`。

- `native-packet-detailed`保存变化的原生事件原文、字段名、解析接受情况、字节数与SHA-256，覆盖商店、海克斯、全场持牌和未知字段。相同事件合并，五秒至少留一次心跳并注明省略数量；接受情况变化也会另记。
- 每包超过256KB时明确标记截断并保存原始字节前缀；非法编码/JSON保留至多64KB原始字节，不能当成已解析事件。
- `decision-state`保存可回放的实际决策输入，开发模式最多每100ms保存有意义的变化。`decision-diagnostic`按任务ID记录派发、失效、各阶段结果、过期结果丢弃、耗时和计算进程错误。
- `app-runtime`记录程序版本、进程及运行时版本，`renderer-console`和无响应事件用于排查界面异常。控制台输出另存为`console.stdout.log`、`console.stderr.log`。
- JSONL按50MB分段、最多9段（约450MB）轮转；异步队列上限8MB/2048条，超出时写明`trace-backpressure`缺口，避免无限积压。被丢弃的决策快照会在后续状态更新时重试。

日志留在本机，不自动上传，也不改变阵容、购买策略或游戏操作。关闭应用会停止采集并刷出已排队日志。发布版仍使用原来的较轻量记录模式。
