# TFTBot 1.3.0

完善“选好阵容之后”的前期过渡体验。

- 桌面选主线后仍可比较与选择过渡，显示已有英雄、商店可补牌与原始观测数据。
- 使用主线家族完整的前期棋盘关联，按人口、持牌种数和升级基础展示三套参考；不再固定取三套低人口方案，不以终局重合度排序。
- 过渡始终由玩家主动选择。已选路线会保留，桌面和浮窗双向同步；仅高亮主线可一键清除过渡。
- 路线按实际内容稳定标识，当前列表刷新后仍能校验旧按钮请求，旧存档按实际棋盘迁移。
- 八人口后面板默认收起，手动展开不会被持牌刷新覆盖；未齐的持牌显示待同步。
- 频繁的持牌统计更新不会关闭固定的英雄详情，也不会仅因过渡展示数据变化就重算战斗模型。

过渡排序是数据参考，不是已证明的最优战斗策略。今天没有真实游戏，真实表现和候选对手字段仍待下次对局验证。

验证：549个测试、类型检查与构建通过；打包EXE通过包含MAINLINE_TRANSITION_SYNC的原生协议联调；设计预览验证桌面/浮窗双向选择与固定详情跨刷新保留；独立工作进程故障隔离通过。
