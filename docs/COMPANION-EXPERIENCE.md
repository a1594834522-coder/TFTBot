# 围绕玩家主线的阵容助手

目标是让玩家把自己选择的阵容玩得更顺、更灵活。系统提供推荐和可比较的数据，玩家决定主线、过渡、变阵与追上限；不自动收窄为唯一答案，不自动操作游戏。

## 一局游戏里的五类支持

| 环节 | 玩家真正需要的帮助 | 数据与交互 |
| --- | --- | --- |
| 选好主线 | 这套属于一、二、三费赌狗，84还是95；核心、前排和可替代位置分别是谁 | 按真实核心、星级、搜牌与终局人口记录分类，保留用户选择 |
| 前期过渡 | 当前来的牌里谁能打工、谁值得留、装备暂时给谁 | 真实前期棋盘关联、持有与缺失、出装兼容；允许与终局零重合，过渡由用户选择 |
| 启动搜牌 | 目前缺首张、关键二星还是双核二星；现有预算大致能到哪 | 等级、现有金币、购买费、同行占牌、有限牌池补齐概率，信息不完整时明确未知 |
| 临场变阵 | 主线抽不齐时有哪些同装备或相近玩法的替代方向 | 默认展示同玩法核心备选，也允许跨类型查看；比较装备、持牌、竞争和补齐难度，不替用户切换 |
| 成型后补强 | 补功能位、换核心、追星或采用更高人口变体，各自需要什么 | 展示真实高人口棋盘、已有英雄及原始统计；逐步增加实际替换成本和对同一候选对手的战力比较 |

## 已落实的交互

- 页面名为“阵容助手”，支持推荐、赌狗、84、95浏览。自动信号只影响推荐顺序，不能设置主线。
- 只有点击“设为主线”才改变当前参考与浮窗高亮；新装备、海克斯或来牌不会自动替换用户主线。可以随时取消或切换。
- 主线候选卡展示主C/前排持牌、同行占主C副本数、过渡已持英雄种数、海克斯机制关联。机制关联不是因果胜率提升。
- 未选择赌狗主线，不因自然来牌或海克斯自动开始追三留牌；普通过渡以两星参考为上限。
- 采用数据中确实保留同一双核、九人口及以上、支持数足够的棋盘作为后期变体。不会把互不相关英雄拼成上限图，也不保证高人口样本均名能复现。
- 复杂比较在桌面；浮窗保留主线/所选过渡头像、剩余牌数、悬停刷新费和战斗参考。
- 1.3.0：已选主线的过渡也能在桌面查看并选择。候选来自该家族完整的前期关联，按当前人口、已持种数与升级基础比较；不以终局重合度筛掉零重合过渡。选定方案跨人口与持牌变化保留，桌面和浮窗双向同步。
- 八人口后过渡面板默认收起，玩家手动展开后保持展开；选用主线不自动勾选过渡。未知持牌显示待同步，不伪装成零张。
- 候选卡可展开“承接与缺口”：把当前场上沿用、已持待上和缺失首张分开，显示实际参考棋盘人口、双核星级副本缺口，以及已穿装备、闲置物品和未来装备承接。仅列标准买价，不混入刷新费、卖牌回收或升级费，不生成拆掉过渡棋盘的指令。
- 1.4.0：“当前换牌”比较购买/自然合成后最多两张牌联动替换的棋盘，显示实际上下场、升级与装备；手选主线在启动/后期另有双核接入或保留方案。每个方案都用相同对手分布与同一真实棋盘基线比较，允许主线方案暂时更弱并如实显示。
- 1.5.0：实时战斗保留拉克丝形态，牌库仍按同一英雄计数；非商店单位按原始模型契约处理，来源确认的假人保持在候选棋盘上。伙伴召唤物只在来源实体与装备保持时参与换牌比较，当前没有猜测具体骑乘者。

## 主线是可达路径，不是一张固定八人名单

玩家选择的是阵容家族。系统应持续回答“用眼下资源怎样把这套玩好”，并允许玩家查看同家族分支和相近装备的外部备选。不能用终局重合度衡量前期过渡，也不能仅因来了一张四费就替换已经两星、带装的打工核心。

| 阶段 | 应比较的目标 | 必须保留的信息 |
| --- | --- | --- |
| 过渡 | 眼下可组成的棋盘、下阶段可达棋盘、装备打工与承接 | 实际星级与上场能力；终局零重合的强过渡正常参与；备战席所有权不等于场上战力 |
| 启动 | 主线首核、关键二星、双核二星，以及能共留的替代核心 | 已见商店、现有预算、同行占牌、买牌费用；抽不齐后的可保留棋盘，不能只看最终成功概率 |
| 成型 | 已完成关键核心后，功能位和羁绊的具体替换 | 在相同对手分布下比较当前与替换后棋盘；缺核心二星不等于一定弱，八个名字齐也不等于稳定 |
| 上限 | 主线追星、高人口变体、五费承接和针对性功能位 | 装备去向、移除单位的功能损失、真实人口与可达成本；九人口样本均名不能当本局升九收益 |

三类玩法共用数据层，采用不同目标：赌狗区分一至三费核心追三与追成后的补强；84重视启动失败仍能打的混合棋盘和双核承接；95重视在获取高费核心前保留强过渡，再比较逐步替换。95不是凑齐五费名单，84也不是4-2一次换完全部目标单位。

最终比较应保留战力、装备承接、可达代价和后续分支几个独立维度，展示少量各有优势的方案。历史聚合用于产生真实候选与装备关联，牌池模型衡量可达性，战斗模型比较具体合法棋盘。未建立因果校准前，不把这些量任意加权成一个“上分分数”。主线与过渡变更始终由玩家确认；日常来牌只刷新事实，不反复弹出改阵提示。

## 尚待完善

当前已经能展示和计算参考，但还不能宣称找到了“最好的过渡”“最好的变阵”或“最高上限操作”。两牌联动比较已使用实际单场模型，完整失败路径、超过两牌的整体变阵、卖牌后的装备承接、更多装备位及多副本跨路线选择仍需完善；实际下一对手候选字段待游戏验证。模型没有站位输入；来源未确认的独立单位、骑乘者更换后的召唤物，以及假人历史属性尚未完整建模。

下一步应把当前两牌联动扩展到更完整的混合棋盘与装备承接，补上非商店单位联动规则，再将具体棋盘的战力用于搜牌失败分支。尚未计算完整路径的最优战力，也未验证排位收益。提示应对应明确的新信息，例如关键升级到手或追三空间不足；不持续发出要求玩家改变路线的指令。
