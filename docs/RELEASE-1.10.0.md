# TFTBot 1.10.0

新增MetaTFT观测引导的三、四牌重组，补上只能比较两牌联动时漏掉的混合过渡和启动方案。

- 继续使用已持英雄与当前合法购买后的实体，不虚构目标牌、星级或穿装。
- 三牌与四牌分别探索，允许保留强打工核心；由同一对手分布下的真实本地单场模型比较，不强制一次换完整队。
- 当前补强、预算落点与装备承接统一部署范围。当前换牌已找到的更强无出售方案会重放并纳入承接基线，避免高估买牌或卖牌收益。
- 保留原有手选主线、过渡及商店高亮，维持墨色界面和精简浮窗。换上/换下的头像直接展示，完整棋盘与装备明细按需展开，避免免费换牌方案看起来无需操作。
- 修正完整覆盖时浮点运算可能让概率上界略低于下界的问题。

新方案是限量候选搜索，仍不代表完整全队最优、自适应搜牌或长期名次收益。只使用最新S18，特殊规则及真实排位效果仍需校准。详见OBSERVED-LINEUPS.md。

验证：635项测试、类型检查和构建通过；9组计算子进程场景与最终EXE的standard、auxiliary、purchase、landing、handoff、mixed六组隔离原生场景通过。混合重组测试先走原链路，再切换合成持牌，验证默认可见上下场头像、展开明细和手选主线保持。所有这些都是工程验证，不是排位收益证明。
