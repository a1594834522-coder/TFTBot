# 补齐优先的可观察商店策略

桌面的留牌目标保留默认“升星优先”，另可主动选择“补齐优先”或“关键二星”。前两种追求任一路双核达标，赌狗的主C为三星；关键二星只追当前尚未二星的核心，任意新增一张二星即达到本次目标。它适合查看一波抽不齐时的中间里程碑，不能把目标变小后的更高概率当作策略更强。

关键二星仍只比较主线与最多两条同玩法备选；赌狗只沿所选路线，主动选择此目标时先看二星，不混入84/95。已有二星、三星以及已经成型的备选不算新进展；主线双核二星后保留目标控件，允许手动切回追三或查看补强。不会自动改变主线、过渡、高亮或执行购买。

“补齐优先”比较每个已揭示商店中所有可负担的核心购买子集，以及继续刷新或停止。购买真正消耗现金和共享池副本，未购买的牌返回后续商店牌池。状态包含各核心仍缺副本、现金和固定英雄格情景。目标完成概率是第一目标，期望余金仅用于完成概率并列时的取舍。主线与同类备选共用同一策略，不提前知道任何未来商店。

在声明的固定等级、正常价格、无出售/未来接装/收入变化模型中，完整展开后以有限钱包Bellman递推比较所有可观察购买决策。不是把每条未来路径的最好结局事后挑出来，也不是完整的上分或战力最优策略。备战席整理仍由玩家处理。副本策略按正常合成规律规划，最终完成概率另核对真实实体星级；不支持的物理合成或未来形态会同时保留达标和战力区间，不能仅因副本数达到三就确认二星。快照尚未完成合并时等待同步。

策略搜索默认最多20,000个状态、2,000,000个候选决策，四、五英雄格分别准备。达到额度后，对未知继续值保留区间；只有能以区间证明确认改进时才改变原升星优先动作，其他决策沿用原规则。条件相同且计算精度容差内，不通过猜测未知分支来牺牲原策略的补齐机会。受限搜索不宣称全局最优。

准备结束后策略表冻结，再独立前向展开各当前购买组合，包含没抽齐与提前停止的落点。表格概率、胜率和余金属于同一已选策略；不会把补齐优先的概率配上升星优先的战力。切换目标时旧表隐藏，计算中的目标和预算控件保留，主线不被修改。

计算进程可复用已经冻结的表：完全展开的表只服务已覆盖的后续状态，受限表要求有序起点、条件和额度完全一致。不会把受限继续值作为最优值续算。每家商店的实体与战力重新验证，详见[PURSUIT-REUSE.md](PURSUIT-REUSE.md)。

## 证据与实际取舍

- 单元测试使用独立物理副本枚举核对最优完成概率与期望现金，另验证混合费用、停止、有限计算下的区间与基础机会、缓存隔离和取消。
- `node scripts/audit-adaptive-pursuit.mjs` 用真实本地MetaTFT模型及同一合成20/40金、24种当前资产组合比较两种目标，检查所有失败质量和当前根保持。
- `node scripts/audit-key-upgrade.mjs` 单独验证20/40金的新增二星目标、既有二星排除、买牌成本、失败分支和区间；不把不同目标的概率当成优劣排序。单元测试独立枚举一店补齐不同核心的并集，避免同店同时完成时重复计算。
- 一个40金样例，四英雄格跳过当前商店后，完成目标由约3.45%升至9.49%，预计余金由约0.69升至8.43。其五英雄格策略触及决策额度，仍如实标注；不会称为已经求得全局最优。
- 同一个20金样例，补齐优先停止了无法完成目标的后续花费，保留更多余金；单场模型参考约89.0%，低于升星优先的约91.8%–94.1%。它不是默认推荐，更不能当作提高名次的结论。

真实胜率、免费刷新可用次数、价格变化与长期收入仍须对应规则与实局校准。这个模块提供明确目标下的条件比较，最终购买和阵容由玩家决定。
