# 当前核心留牌与后续机会成本

在阶段4以后、至少7级且玩家已选择主线时，对当前商店中的主线和最多两条同类备选核心，枚举合法的无出售购买组合。相同资产结果合并。赌狗不混入84或95方案；主线成型后交给现有补强与上限模块。

每个组合先由真实交易账本购买，处理现金、物理副本、实际形态、升星与穿装。默认未来商店采用升星优先规则：先完成当前可完成的升星，再选离下一次升星更近的核心，再按主线顺序。也可主动选择补齐优先，按已揭示商店重新比较购买子集与是否继续花费。所有决策只使用已经揭示的商店；详见ADAPTIVE-PURSUIT.md。

比较包括跳过当前商店，以及同时留主线与备选的组合。当前购买也占总预算，预算外现金保留；不能把当前卡牌免费加入未来棋盘。已成型的备选不阻止比较当前主线购买，但未来无需继续为这条已成路线刷牌。

四个、五个英雄格分别计算。每个方案的全分布都包含失败落点，分别输出所选目标达标概率、加权单场模型参考和期望剩余金币。可主动选择“关键二星”，查看任一当前未二星核心新增二星的机会；已有二星不计入，赌狗仍不跨玩法。三个指标不合并为一个分数，也不自动替玩家决定。

## 计算与边界

- 每个根独立保留概率质量和状态额度。默认最多展开20,000状态；共享的是同一牌池与未来策略的转移，不共享额度或推定结果。现金足以购买整店时，转移缓存按支出复用，不能复用绝对余额。
- 模型评分默认384个落点组合，按购买根和商店情景轮流分配，优先各自高概率落点。未评分、未展开、未知对手的质量都保留。
- 同一计算进程可复用条件相同的转移与冻结策略，不能复用整张旧建议表。完全展开表核对后续状态覆盖；受限表要求完全相同的有序起点和额度。当前买牌、合成、装备与实际对手每次重新核对，详见PURSUIT-REUSE.md。
- 相同模型下复用完整有向对局结果；固定对手及权重下复用棋盘加权值和特征支持检查。每个实际候选的实体、穿装和召唤物来源仍重新验证。缓存只保存数值，不持有推理张量；淘汰跨批缓存数据时，本批所需向量保留到计算结束。
- 已评分的原棋盘若在落点中仍能按原实体、星级、形态和装备合法重放，可提供战力下界。需要重新核对召唤物来源及棋盘支持。合成改变或吞掉原实体时不能借用这个下界。已知当前形态可使用，未确认未来形态不会猜测。
- 达标概率也检查实际合成后是否存在对应星级实体。副本数已齐但合并快照未齐时等待同步；未来装备合成、形态或空间未确认的分支保留达标区间，不冒充确认二星。副本策略仍是正常合成条件下的规划，不是完整物理动作最优解。
- 当前与未来部署比较原两牌邻域和限量的MetaTFT观测引导三四牌重组，并加入仍合法的已知棋盘。不是完整全队最优搜索，也不是自适应的长期名次策略。补齐优先只优化声明副本目标，可能牺牲当前战力。
- 固定当前等级与对手，不计未来收入、出售、接装、站位或升级；刷新按当前标准价格，不含尚未同步的免费次数和价格变化。沿用明确标注的S18 PBE规则，真实排位效果待验证。
- 单场模型区间表示未评分与未知质量带来的上下界，不是统计置信区间，更不是上分或最终名次概率。

## 复现

`node scripts/audit-search-landings.mjs --current-purchases` 使用合成原生协议持牌和真实本地MetaTFT模型，绝不接入游戏。环境变量 `TFTBOT_AUDIT_BUDGET`、`TFTBOT_AUDIT_STATES`、`TFTBOT_AUDIT_BOARDS` 可改变压力检查条件。

`node scripts/audit-pursuit-throughput.mjs` 以独立冷进程、同一40金/24种资产组合，比较不复用192落点、复用192落点、复用384落点。一次实测约5.46/3.03/3.85秒；前两者48个区间数值一致，翻倍评分后48个区间均收窄，补齐概率与预计余金保持。示例跳过商店的四英雄格完整评分质量从8.1%升至16.9%。这些是单个合成场景的工程证据，不能作为最坏时延保证或真实排位收益。真实连续快速刷新时会取消旧任务，当前商店的即时补强先发布，复杂留牌结果需要稳定局面才能完成。

单元测试以独立组合计数核对不放回抽样、机会成本、余金、预算外保留、缓存隔离、未知质量、实体合成、已成型备选、已知与未来形态及召唤物来源。计算进程和隔离原生事件测试继续验证到桌面表格的链路。
