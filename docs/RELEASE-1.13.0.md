# 1.13.0 · 新增关键二星与桌面整理

4-2/4-3启动时，一波预算未必能让双核全部二星。留牌比较新增“关键二星”目标：比较买入当前核心、兼留备选或跳过之后，在相同预算内新增任一关键二星的机会，并独立显示搜后模型参考和预计余金。

## 使用

手选主线后，在“阵容助手 → 当前补强 → 这家店怎么留”的原目标菜单选择：

| 目标 | 后续购买参考 | 达标条件 |
| --- | --- | --- |
| 升星优先（默认） | 先完成可完成的升星，再按副本接近程度和主线顺序购买 | 任一路双核达到目标，赌狗主C为三星 |
| 补齐优先 | 依据已揭示的商店比较购买子集、继续或停止 | 同上；先比较完成机会，再以余金取舍 |
| 关键二星 | 同样按已揭示商店调整购买 | 当前尚未二星的核心中，任一新增二星 |

关键二星排除已有二星、三星及已成型备选的旧进展。赌狗仍只沿所选路线，二星目标不会自动切到追三。达到目标后保留菜单，玩家可以手动切换。主线、过渡、高亮和实际游戏操作均由玩家决定。

完成概率现在核对实际实体星级。副本达到三而快照未完成合并时等待同步；未来形态、装备合并或空间未确认时保留达标区间。副本策略仍以正常合成规律规划，不能称为完整物理动作最优策略。

## 桌面

延续墨色底、米白文字和少量陶土色，使用衬线标题与细分隔线。热门阵容去掉背景插画和彩色评级底块，列表更平整，英雄费用色继续用于辨识。选中主线用细线标记，复杂比较仍在桌面，局内浮窗保持紧凑。

## 验证

- 666项测试、类型检查和桌面构建通过。独立组合计数验证多种新增二星的并集，同店同时完成不会重复计数；已有二星、未合并快照、未知装备合成与未来形态都有覆盖。
- 12个Electron计算进程场景通过，包括实际展开的关键二星策略。
- 最终便携包使用隔离原生协议事件验证到桌面：当前购买/跳过、预算同步、三种目标切换及切回、装备承接。主线保持，最小窗口表格无横向溢出。协议测试不等于真实游戏验证。
- `node scripts/audit-key-upgrade.mjs` 使用真实本地MetaTFT模型、合成20/40金局面，分别核对24种当前资产组合、48个商店情景。一次实测约0.72/6.21秒；40金五英雄格策略触及2,000,000候选额度，未宣称全局最优。
- `node scripts/audit-adaptive-pursuit.mjs` 复核原两种目标的全部当前购买根，完整失败分支、模型条件与现金核算保持。

## 使用边界

三种目标不同，较高达标概率不代表更高战力或排名。当前固定等级、对手及装备，不含未来收入、出售、接装、升级和未同步的免费刷新次数/价格变化；商店四、五英雄格分别计算。对手未知时使用明确标注的全场等权参考。复杂场景需要稳定局面数秒，状态变化会取消旧结果。

仍依赖本机`E:/amumu`原生组件。真实下一对手标记、连续整局稳定性及实际排位收益尚待验证；版本测试不能替代这些证据。
