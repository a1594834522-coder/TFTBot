# TFTBot 1.3.1

阵容候选新增可展开的“承接与缺口”，展示当前棋盘到一套真实参考棋盘的资产差异：

- 场上沿用、已持待上、缺失首张分别展示，避免把备战席资产视为已经形成战力。
- 显示目标人口与人口差、核心二星或赌狗核心三星的副本缺口。
- 买价仅为缺失首张的标准买价，刷新费、升级费、特殊价格与卖牌回收均不包含，不展示虚假的变阵净成本。
- 双核已穿物品、未绑定物品、需从打工英雄承接的物品分别显示；其他保留英雄的装备不重复分配。明细缺失时显示待同步。
- 面板默认收起，手动展开后跨数据刷新保持展开；不添加局内浮窗文案，也不切换玩家主线或执行买卖。

同步补充完整对局的主线体验设计：过渡、启动、成型、上限采用不同目标；三类玩法共用数据，分别建立目标。后续重点是启动未成时的混合棋盘与具体替换后的对战比较。

验证：555个测试、类型检查、桌面构建通过；隐藏桌面预览验证事实展示、布局与跨刷新保留，并保留原有主线/过渡双向同步验证。打包EXE通过采集、阵容助手、搜牌、胜率、仙灵与浮窗的原生协议联调。真实排位收益仍待验证。
