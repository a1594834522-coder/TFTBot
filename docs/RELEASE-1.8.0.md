# TFTBot 1.8.0

新增桌面“装备承接”，比较带装打工牌的出售、当前核心购买和真实接装。

- 先计算不出售、使用装备栏现有物品的参考，避免把免费接装收益算给卖牌。
- 出售返还与接装使用同一装备实体；散件真实消耗并考虑不同合成顺序，保留核心已穿装备与来源约束。
- 比较核心上场后的模型变化，允许一星主线暂时更弱；每名出售英雄都必须贡献接装，不夹带无关卖牌。
- 展示出售对象、接装对象、物品、回收/购买/余额与模型差值。装备栏容量未确认时明确显示空余格条件；不执行任何游戏操作。
- 装备规则使用用户提供的S18 PBE数据，核对149个装备条目、全部商店英雄羁绊及已知出售机制。临时装备等额外规则不当作普通返还；海克斯或装备栏未齐时说明等待原因。

623项测试、类型检查与构建通过；最终EXE通过standard、auxiliary、purchase、landing、handoff五组隔离原生集成验证，已于2026-10-21更新本机发布目录，未自动启动。详见 `EQUIPMENT-HANDOFFS.md`。真实排位收益、任意整体变阵和未来搜牌后的自适应接装仍未验证或完成。
