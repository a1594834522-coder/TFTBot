# TFTBot 1.6.0

让买牌建议区分即时收益与免费换牌收益，并修正当前商店和未来刷牌费用的表达。

- 新增“商店补强”：相对当前持牌可免费摆出的最好棋盘，计算各购买组合的额外模型收益。删除无额外收益和被更便宜方案替代的购买；保留成本/战力不同的少量选择，不任意换算金币与胜率。
- 两张以上购买作为整组展示，可展开上场、下场、升星明细。玩家点击后才同步商店高亮，主线与过渡保持用户原选择；实体、装备、商店、钱包、回合或对手变化后旧高亮失效。
- 修复新增嵌套偏好跨Vue/Electron IPC的序列化，并在偏好初始化期间禁用购买选择，避免首次点击丢失。
- 目标已经在商店时，显示“无需刷新”、标准购买价和钱包可买数量，不依赖全场牌池或等级完整；旧帧/断开后清除实时断言。未知金币保持未知。
- 未来下一张费用显示4至5英雄槽的参数范围，涵盖仙灵占格的不确定性。这不是置信区间、保底，也没有假装已精确确认仙灵刷新周期。
- 诊断改为默认128MB轮转，保存实际决策关键状态并排除纯时间戳重复；正常EXE默认启用本地诊断，工作区启动脚本自动连接只读采集。新增整个保留环的审计和原时钟状态导出，拒绝覆盖原始证据。

验证包括600个测试、类型检查、构建、真实本地模型离线组合审计。最终打包EXE已通过普通、召唤物和购买组合三种隐藏原生通道联调，包含选择/取消/商店高亮、主线过渡同步及当前可买/未来费用显示；所有协议测试使用隔离通道和合成数据。

本机正式目录已更新到 `desktop-release/TFTBot-win32-x64`，旧版备份 `desktop-release/previous-20261021-155857`。发布时未发现游戏进程，本次没有自动启动或重启程序。

边界：即时购买只在当前商店与最多两牌联动的部署范围比较，装备仍留在当前实体上。长期留牌、完整搜牌失败后的混合棋盘、卖牌接装及全路径变阵尚未完成；正式服特殊规则与真实下一对手候选仍待验证。没有运行真实对局或证明排位收益。详见 `SHOPPING-TACTICS.md`、`LIVE-DIAGNOSTICS.md` 与 `COMPANION-EXPERIENCE.md`。
